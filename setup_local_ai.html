Install llama.cpp
The inference engine — Metal GPU accelerated
▾

llama.cpp is the inference engine that runs the model. Choose Homebrew for simplicity, or build from source for the latest features.

Installation method
bash
brew install llama.cpp

# verify it worked
llama-server --version
bash
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp

# build with Metal (Apple GPU acceleration)
cmake -B build -DGGML_METAL=ON
cmake --build build --config Release -j $(sysctl -n hw.ncpu)

# add binaries to PATH (add to your ~/.zshrc too)
export PATH="$PATH:$(pwd)/build/bin"
ℹ Building from source gets you the very latest optimizations. Worth it if you plan to use this regularly — Metal performance improvements land frequently.

Download Qwen3-27B
~17 GB GGUF download via HuggingFace CLI
▾

The model is hosted on HuggingFace in GGUF format (the standard format for llama.cpp). We use bartowski's quantized versions — consistently the best quality quantizations available. View all quantizations →

Step 1 — Install the HuggingFace CLI
bash
pip3 install huggingface_hub
Step 2 — Download the model
bash
# Recommended: Q4_K_M (~17 GB, best speed/quality balance on 32 GB RAM)
huggingface-cli download \
  --local-dir ~/models/qwen3-27b \
  bartowski/Qwen3-27B-GGUF \
  "Qwen3-27B-Q4_K_M.gguf"

# On 64 GB RAM: use Q6_K for near-lossless quality (~23 GB)
# huggingface-cli download --local-dir ~/models/qwen3-27b \
#   bartowski/Qwen3-27B-GGUF "Qwen3-27B-Q6_K.gguf"
⚠ Download takes 10–30 minutes depending on your connection. The file lands at ~/models/qwen3-27b/Qwen3-27B-Q4_K_M.gguf. Keep your Mac awake (caffeinate or disable sleep).

Start llama-server
OpenAI-compatible local API on port 8080
▾

This launches an OpenAI-compatible HTTP API on your machine. Any tool that accepts a custom --openai-api-base URL will immediately work with it.

Launch command
bash
llama-server \
  --model ~/models/qwen3-27b/Qwen3-27B-Q4_K_M.gguf \
  --ctx-size 32768 \
  --n-gpu-layers 99 \
  --threads 8 \
  --host 127.0.0.1 \
  --port 8080
What the flags do
FlagEffect
--n-gpu-layers 99Offloads all layers to Metal GPU (fast — use this)
--ctx-size 3276832k token context. Increase to 65536 on 64 GB RAM
--threads 8CPU threads for prompt processing. Match your core count
Verify it's running
bash
curl http://127.0.0.1:8080/v1/models
✓ You should get a JSON response listing the model. Once you see that, you have a fully OpenAI-compatible local API. Keep this terminal window running while you use the agent.

Tune for coding tasks
Thinking mode · system prompts · context tips
▾

These optional steps will significantly improve output quality, especially on complex multi-file refactors.

Enable Qwen3 thinking mode

Qwen3 has a built-in chain-of-thought toggle. Adding /think to your prompt or system message makes it reason step-by-step before answering — dramatically better for hard tasks, at the cost of some speed.

prompt
# Add to first user message or system prompt:
/think

# Faster responses (no reasoning chain):
/no_think
Recommended system prompt for coding agents
system prompt
You are an expert software engineer working on this codebase.
Always read and understand existing code before making changes.
Prefer minimal, targeted edits over full rewrites.
Explain your reasoning before showing code.
When unsure about intent or requirements, ask rather than assume.
Context window guide
ctx-sizeRAM costGood for
8k–16klowSingle file edits, focused tasks
32kmediumMulti-file refactors (recommended)
64k–128khighLarge codebase reasoning (needs 64 GB RAM)
💡 For HuggingFace codebases: feed the model the specific module files relevant to the task rather than the full repo. Focused, relevant context outperforms huge context on most coding tasks.
