Task 5 · Jatinder Syall — share findings on iDictate & ChatGPT Android repos, and feasibility for a click-to-solution flow-diagram demo
iDictatepetepiet.github.io/iDictate ↗

Open-source Android & Wear OS dictation app. Uses Whisper for transcription and Claude for summaries and action items. On-device encrypted storage, no accounts or tracking, GPL-3.0.

Relevance: near-identical pipeline to Happy Cue — record → transcribe → Claude-generated action items — already proven as a working open-source reference.
gpt_mobile (Taewan-P)github.com/Taewan-P/gpt_mobile ↗

Android chat app supporting multiple LLM providers at once (OpenAI, Anthropic, Google, Ollama), bring-your-own-key, Material3 + Compose.

Relevance: reference for a swappable-model backend if different workflow steps end up calling different LLMs.
chatAir (flyun)github.com/flyun/chatAir ↗

Native Android app supporting ChatGPT, Gemini, Claude and DeepSeek, with custom endpoint support and markdown/code rendering.

Relevance: more production-polished than gpt_mobile — useful UI patterns for rendering structured AI output.
chatgpt-android (skydoves)github.com/skydoves/chatgpt-android ↗

Architecture-sample repo: OpenAI chat API on Android via Jetpack Compose, Coroutines/Flow, Hilt, WorkManager.

Relevance: not diagram-specific, but a clean UI/data-layer separation worth copying for the app's architecture.
